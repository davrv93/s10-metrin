# Problemas de acceso por el Servicio de SQL Server

Fuente: https://documentacion.s10peru.com/problemas-acceso-servicio-sql-server/

Cuando el servicio de SQL Server de la base de datos o del equipo donde se encuentran las licencias se detiene debido a algún conflicto con el sistema o no inicia automáticamente luego de encender o reiniciar, al intentar ingresar al S10, el aplicativo mostrará  los siguientes mensajes:
En esos casos se debe revisar y encender el servicio SQL Server (MSSQLSERVER)
1. Se ejecuta el comando “Services.msc” desde ejecutar, o se busca la herramienta Servicios en inicio.
2. En la herramienta Servicios, debemos ubicar el servicio SQL Server (MSSQLSERVER).
3. Clic derecho sobre el servicio y presionar Iniciar.
