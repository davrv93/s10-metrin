# Manual de Aprobaciones

Fuente: https://documentacion.s10peru.com/manual-de-aprobaciones/

Table of Contents
Toggle
1. Generalidades
1.1 Qué es la Aplicación de Aprobaciones S10
Es una aplicación móvil conectada a S10 ERP, que permite a las personas designadas como aprobadores, tomar decisiones de aprobar, observar o rechazar un documento.
1.2 Objetivos de la Aplicación:
● Agilizar la toma de decisiones para su ejecución oportuna.
● Organizar mejor la toma de decisiones mediante la diversificación de responsabilidades dentro de la empresa
● Unificar la gestión de aprobaciones mediante una aplicación única y con conexión nativa con el S10 ERP
1.3 Hagamos un tour:
1.3.1 Descarga la Aplicación :
Para acceder a la aplicación de Aprobaciones, entramos desde nuestro celular a la tienda de aplicaciones, sea Appstore ( Si tienes iPhone) o PlayStore (si usas Android) y le damos en descargar.
1.3.2 Acceder a la Aplicación:
Una vez dentro de la app colocar tu usuario y clave
Ahora elige la corporación a la que deseas conectarte, tal como señalamos en la siguiente imagen:
1.3.3 Vista General:
La aplicación muestra 4 pestañas que se deslizan de manera horizontal para mostrarte el estado de cada documento, y saber si la solicitud esta:
● Pendiente
● Aprobada
● Observada
● Rechazada
● Pestañas de Pendientes:
En esta sección se verán las solicitudes pendientes de aprobar.
● Pestaña de Aprobados:
Vemos las solicitudes que ya hemos aprobado anteriormente.
● Pestaña de Observados:
Vemos las solicitudes en las que hemos escrito algún comentario u observación para que esta vuelva a ser revisadas.
● Pestaña de Rechazados:
Nos muestra el registro de todas las solicitudes que hemos rechazado anteriormente.
● Menú lateral:
Este menú
nos muestra las opciones de:
Lista de aprobaciones:
Para tener acceso rápido a las solicitudes por aprobar.
Configuración:
Desde aquí puede realizar el cambio de Contraseña
Cerrar sesión:
Salir de tu sesión de aprobador
2. Manual para el usuario Aprobador
2.1 Los tipos de solicitudes:
Para comenzar siempre elige entre los diversos tipos de solicitudes a aprobar, estas pueden ser:
● Pedidos
● Órdenes de pago
● Órdenes de compra
● Órdenes de servicio
● Contratos
● Subcontratos
● Subcontratos – Valorizaciones
● Subcontratos – Autorización cobranza
● Subcontratos – Autorización Pago
2.2 Busca y elige solicitud que deseas revisar:
Una vez dentro, busca o elige la solicitud específica que deseas revisar para después aprobar, rechazar u observar.
2.3 Aprueba, Observa o Rechaza una solicitud:
Después de haber revisado la solicitud, toma alguna de las siguientes decisiones:
● Aprobar: si estas de acuerdo con la solicitud, y deseas que se ejecute.
● Rechazar: si no estas de acuerdo, y decides no aprobarla.
● Observar: si decides hacer un comentario u observación sobre la solicitud antes de aprobarla.
2.4 Deja una observación:
Cuando le des en el botón observar
deja un comentario breve que justifiques el por qué necesita ser revisado.
2.5 Revisa cada tipo de solicitud:
A continuación mira los detalles de cada solicitud antes de tomar la decisión de aprobarla, rechazarla u observarla.
