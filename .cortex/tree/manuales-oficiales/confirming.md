# Confirming

Fuente: https://documentacion.s10peru.com/confirming/

Requisitos:
Para poder trabajar con Confirming se debe tener en los catálogos de exportación un formato con el nombre “Confirming”.
Considerar que en las últimas actualizaciones de S10 de fecha Marzo 2020 estos formatos ya fueron incluidos para todos los bancos, por lo que si no cuenta con este, debe actualizar su S10 o contactar con el área de Soporte.
Otro requisito necesario, consiste en tener un tipo de documento con nombre CONFIRMING, configurado con tipo documento base 45.
Con estos requisitos cubiertos ya se podría usar el proceso de CONFIRMING.
Uso en Administrativo
Habiendo ya verificado los formatos, podrá hacer uso de “Confirming” eligiendo el formato al momento de crear una Orden de Pago.
La elección del formato se habilita al marcar el check de “Pago Electrónico” y elegir una “Cuenta bancaria”.
Se Agrega el documento a canjear y se graba la Orden de pago.
Se envía a aprobación y se aprueba como una Orden de pago normal, finalmente ya podrá generarse el Pago con el canje del Confirming. Los permisos para aprobar este tipo de orden son iguales a los usados para las demás órdenes.
Al grabar el pago, de forma automática, se generará un documento tomando como base el tipo de documento creado en los requisitos.
Este documento podremos verlo desde la pestaña Tipo de Pago una vez grabado el Pago.
El documento generado, quedará disponible para que sea pagado cuando el banco les debite.

El texto completo también está troceado en `kb/fragmentos.jsonl` y se cita con el nombre del manual y la página.
