1. CALIDAD MÓVIL PARA EL ERP
1.1 Generalidades
1.1.1 Servicio
Calidad móvil es un servicio en la nube que S10 brinda a los usuarios del S10 ERP edición Especial.
Esta aplicación permite realizar control de calidad a las actividades de un proyecto en un dispositivo móvil, Celular o Tablet.
Permite el registro de la información en forma conectada o desconectada.
1.1.2 Esquema General
1.2 Registro de información
1.2.1. Asignación de Protocolos
Los protocolos generales son registrados en un catálogo.
Este catálogo tiene 3 niveles definidos por el usuario.
Cada protocolo tendrá una lista de características, los cuales serán posteriormente calificados en las actividades.
Ingrese al escenario de
Ficha de Protocolos
para realizar el registro de los protocolos y sus características.
Las características se definen en un catálogo de 2 niveles, para luego ser asignado al protocolo.
Puede ser de tipo Detalle o Titulo.
Asigne uno a uno o en forma masiva el protocolo relacionado a cada actividad, desde el escenario
Asignación de Protocolos
.
En la ventana de especificaciones es donde se asignan las propiedades de cada actividad.
1.2.2 Publicación de Actividades del Proyecto
En el módulo de Gerencia de Proyectos, en el escenario de Asignación de Protocolos a Actividades, se indica las actividades que serán publicadas. En una columna se muestra este dato.
Para la publicación al móvil puede hacerse de 2 formas, indicando individualmente la publicación o si todo el proyecto será publicado.
Se publica cada proyecto en forma independiente.
Antes de la publicación, el proyecto debe tener publicado al menos una actividad.
Al ingresar a la ventana de publicación por primera vez, en la pestaña
“
Por Publicar”
se muestra a los revisores y supervisores asignados a las actividades publicadas. Haga clic en el campo
¿publicar?
y luego clic en el botón
Publicar
.
También permite realizar la publicación para invitados, sean o no usuarios del S10. Use la opción
Adicionar Invitado
, y este será habilitado como usuario en la aplicación móvil, pero solo para ver la información ya registrada.
También permite realizar la publicación para invitados, sean o no usuarios del S10. Use la opción
Adicionar Invitado
, y este será habilitado como usuario en la aplicación móvil, pero solo para ver la información ya registrada.
Todas las publicaciones en todos los proyectos pueden ser visualizadas en el escenario: Publicación Calidad Móvil.
Desde aquí podrá identificar los proyectos que fueron enviados al móvil por cada usuario y el estado en que se encuentran.
Aquí tenemos las siguientes opciones:
Cambiar a estado concluido
: Permite cerrar el proyecto para el usuario seleccionado y ya no podrá ser editado y sincronizado desde el dispositivo móvil.
1.2.3 Actividades de Aplicación Móvil – Calidad Móvil
Los datos de los usuarios que accederán a la aplicación móvil, deben ser proporcionados al área de ventas de S10 al momento de contratar el servicio. Debe indicar el correo electrónico del usuario y el RUC de la empresa asociada.
También es necesario proporcionar el IP público de la base de datos, así como el nombre de ésta.
Esta aplicación está disponible para Android y IOS. Busque la aplicación en Play Store o App Store según el dispositivo que tenga.
Luego de descargar la aplicación es necesario validar sus datos para la activación.
Luego de ingresar sus datos y hacer clic en el botón
Siguiente
, entonces se habilitará un nuevo botón para generar el código de activación.
Se le enviará un mensaje a su correo electrónico con el código de activación.
Esté código debe ser registrado en el móvil, y luego se pedirá ingresar una nueva contraseña.
De esa forma ya quedará activada la aplicación en el dispositivo móvil.
Se realizará la sincronización de la información: proyectos, actividades, frentes, destinos específicos, etapas, la que es guardada en el mismo dispositivo.
Cabe resaltar que para que se realice la sincronización, se debe haber publicado antes el proyecto para el usuario, el cual se describió en el capítulo 2.2.
1.2.4. Cierre del proyecto
Una vez que se haya terminado de registrar la información desde el dispositivo móvil, es necesario que se dé por terminado la calificación de las actividades del proyecto, para ello debe cambiar el estado en cada línea, a
Concluido.
De esta forma los usuarios ya no tendrán acceso a la información del proyecto, desde el dispositivo móvil.
2. CALIDAD MÓVIL PARA LA APP
2.1 Instalación
2.1.1 Instalación y configuración
Para poder activar la aplicación es necesario que se haya publicado antes el proyecto para el usuario, desde el módulo S10 Gerencia de Proyectos.
Esta aplicación está disponible para Android y IOS. Busque la aplicación en Play Store o App Store según el dispositivo que tenga.
Luego de descargar la aplicación es necesario validar sus datos para la activación.
Luego de ingresar sus datos y hacer clic en el botón
Siguiente
, entonces se habilitará un nuevo botón para generar el código de activación.
Se le enviará un mensaje a su correo electrónico con el código de activación.
Esté código debe ser registrado en el móvil, y luego se pedirá ingresar una nueva contraseña.
De esa forma ya quedará activada la aplicación en el dispositivo móvil.
Luego de ello se muestra en una lista todos aquellos proyectos publicados para el usuario. Seleccione el proyecto a trabajar.
Entonces se realizará la sincronización de la información del proyecto seleccionado: actividades, frentes, destinos específicos, etapas, la que es guardada en el mismo dispositivo.
2.2. Producción
Al seleccionar esta opción se muestran otras opciones
2.2.1. Calidad de Responsables
Ingrese a esta opción para realizar la calificación de las actividades y sus características.
En esta pantalla se muestra en forma gráfica el estado de las actividades.
Los estados de la actividad pueden ser: Nuevo, en proceso, completado, revisado, aprobado, no conforme. Cada uno de estos tiene un color predefinido, lo cual permite distinguirlos a simple vista.
Dentro de cada barra se muestra el número de actividades que representa el ítem. Si el alcance está por defecto, es decir, por actividades, se mostrará valor 1. Si el alcance es diferente a Actividad, entonces mostrará el número de actividades asignados.
La parte superior es la sección del alcance y los filtros.
El alcance se refiere a lo que se mostrara en la primera pantalla: Actividades, Frente, Etapa, Destino Específico, Supervisor, Revisor o Responsable. Por defecto se muestran las actividades.
Para cambiar el alcance haga clic en uno de los botones y luego en el botón de la lupa. Entonces los ítems mostrados serán del alcance seleccionado.
Para desactivar el alcance seleccionado, vuelva a pulsar sobre el botón del alcance.
Para acceder a las características de la actividad debe pulsar sobre la barra. Luego se mostrará la lista de características. Cada característica tiene un estado, representado por un color.
Es aquí donde el usuario que sea Revisor o Supervisor cambiará el estado cuando realice su labor de revisión.
Si selecciona el estado
No Conforme
, automáticamente se generará una observación y un registro de cambio de estado. Ingrese los detalles sobre la no conformidad: texto, imagen y el tipo de falla.
2.2.2. Acumulado de fallas
Muestra las actividades con alguna falla o no conformidad registrada. Estas actividades son resaltadas por su origen: planilla o subcontrato.
Es posible acceder a las características de cada actividad pulsando sobre la barra.
2.2.3. Tipo de Falla
Muestra todos aquellos protocolos en los que existen características con estado NO CONFORME, es decir ha sido calificado con algún tipo de falla.
Puede cambiar el alcance para visualizarlo de acuerdo a sus necesidades.
Pulse sobre la barra para ver el detalle por actividades y características
2.3. Otros
2.3.1. Indicadores de Sincronización
Muestra en forma cronológica por usuario las cargas y descargas realizadas.
2.3.2. Indicadores de Toma de Datos
2.3.3 Sincronizar Descarga
Esta opción permite obtener la información de las actividades desde la base de datos del S10 ERP.
La primera vez que sincroniza, se obtiene toda la información del proyecto desde la base de datos del S10 ERP, y es guardada en el dispositivo móvil, esto comprende:
Actividades
Frentes
Destinos
Específicos
Revisores
Supervisores
Responsables
2.3.4. Sincronizar Carga
Esta opción permite enviar información registrada en el dispositivo móvil hacia la base de datos del S10 ERP.
Una vez que la información se encuentre registrada en el dispositivo móvil, y se haya realizado alguna calificación, cuando se utilice esta opción, se verifica si se hizo alguna modificación en los datos, de ser así la información será actualizada en el S10 ERP.
Cuando existan datos pendientes por enviar al S10 ERP, se visualizará en un fondo de color rojo el número de cambios pendientes.
