# Cómo realizar una copia de seguridad de base de datos

Fuente: https://documentacion.s10peru.com/realizar-copia-seguridad-base-datos/

Abre tu Módulo de S10, ve al escenario de
‘Utilitarios’
luego da click en
‘mantenimiento de base de datos’
Se abre una ventana llamada
«Mantenimiento de Base de datos», dale clic en el botón
‘Siguiente’
Darle clic en el botón de
‘Copia de seguridad de base de datos’
Después escogemos la base de datos que deseamos que sea copiada, y le damos clic en el botón ‘
Siguiente’
Le asignamos un nombre a la copia de la base de datos  y le damos clic en ‘
Siguiente’
Procedemos a darle clic en
‘Copiar’
para que comience el proceso
Luego de esto se generará la copia de base de datos, y este se ubicará en la carpeta
C:\S102000\Backup
